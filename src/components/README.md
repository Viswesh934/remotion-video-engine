# Components

This directory contains reusable UI components for the Remotion Video Engine.

## Purpose
- Reusable visual elements (Browser, Terminal, CodeBlock, Timeline, etc.)
- Self-contained components with props-based configuration
- Designed for composition and AI-agent compatibility

## Guidelines
- Each component should be in its own file
- Use TypeScript for type safety
- Keep components pure and predictable
- Minimize dependencies (React, Remotion, TypeScript, plain CSS only)
